# 🎨 Contrast Checker | Mindric Lab

Ein modernes, visuelles Tool zur Überprüfung von Farbkontrasten für barrierefreies Webdesign. Entwickelt mit dem Fokus auf UI-Ästhetik und einfacher Bedienung.

> **Status:** ✅ Live & Stable
> **Demo:** [Hier klicken](https://deine-domain.de/tools/contrast-checker) ## ⚡ Features

* **Echtzeit-Analyse:** Sofortiges Feedback zum Kontrastverhältnis (Ratio).
* **WCAG Compliance:** Prüft automatisch auf **AA** (4.5:1) und **AAA** (7:1) Standards.
* **Smart Input:** Unterstützt HEX-Code Eingabe und visuellen Color-Picker.
* **Quick Swap:** Tausche Hintergrund- und Textfarbe mit einem Klick (`⇅`).
* **Glassmorphism UI:** Modernes Design mit Blur-Effekten und Smooth Transitions.

## 🚀 Nutzung (Local)

Da dieses Tool als "Single File Solution" gebaut ist, brauchst du keine Installation.

1.  Lade die Datei `index.html` herunter.
2.  Öffne sie per Doppelklick in einem beliebigen Browser (Chrome, Edge, Firefox).
3.  Fertig!
