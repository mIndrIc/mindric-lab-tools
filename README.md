## 📅 Wöchentlicher Content-Plan / Weekly Content Schedule

Kleine, praktische Web-Tools zum direkt Nutzen.
*Small, practical web tools ready to use.*

- **Format:** HTML/CSS/JavaScript
- **Länge:** ~100-150 lines
- **Link:** CodePen

### 🎮 **Wednesday – Mini Game**
Schnelle, addictive Browser-Spiele für zwischendurch.

- **Format:** HTML/CSS/JavaScript
- **Länge:** ~150-200 lines
- **Link:** CodePen

## 🎨 Was ist "Vibe Coding"?

**Vibe Coding** = Programmieren mit Kreativität, Gefühl und Spielspaß.
Nicht um perfekten Code, sondern um visuelle Effekte, Automatisierung und praktische Werkzeuge, die Spaß machen.

**Vibe Coding** = Programming with creativity, feeling and fun.
Not about perfect code, but about visual effects, automation and practical tools that are enjoyable.
